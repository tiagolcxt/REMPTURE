Endless Runner - Godot 4.2 (Versão Expandida)
Este projeto é um jogo do gênero Endless Runner desenvolvido na engine Godot 4.2. Esta versão é um fork aprimorado do projeto original de rasalagean, contando com novos assets visuais e mecânicas de gameplay adicionais.

🚀 O que há de novo?
Diferente da versão base, esta versão inclui:

Novas Mecânicas: (Ex: sistema de pulo duplo, novos obstáculos, multiplicadores de score).

Assets Atualizados: Novos gráficos e sprites para uma identidade visual única.

Refatoração: Melhorias no código para facilitar a implementação de novos elementos.

🛠️ Como Executar Localmente
Clone o repositório:

Bash
git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
Importe no Godot:

Abra o Godot Engine 4.2.

Clique em "Importar" e selecione o arquivo project.godot na pasta raiz.

Execute:

Pressione F5 para iniciar o jogo.

📦 Exportação e Web
O jogo está configurado para exportação multiplataforma. Caso utilize o GitHub Pages para hospedar a versão web, certifique-se de configurar a resolução da janela no Godot para evitar quebras de layout em navegadores redimensionados.
